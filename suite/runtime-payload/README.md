# Canonical runtime payload

These files are the non-utility inputs used to construct a fresh
`Conformance Suite.dmk`. Utility COM files come from `suite/build`;
`BDSA.TMP` and `BDSB.TMP` are generated from the current BDOSTEST binary.

No third-party CP/M utility is included in the runtime payload. The BT data
files and CPMTEST.CFG are controlled suite fixtures. `BTRO.DAT` is marked
read-only by the runtime-image builder.

The data files are generated by `tools/build_runtime_payload.py`. Each record
contains a repeated, human-readable marker such as `ONE-000`, `MULTI-002`, or
`BIG-129`; rebuilding the payload is deterministic.
