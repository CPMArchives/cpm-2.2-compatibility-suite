OBJECTIVE

Determine whether common CP/M 2.2 applications expose additional
compatibility requirements not fully captured by previous investigations.

Previous investigations established:

- CP/M interfaces;
- system behavior;
- storage behavior;
- memory behavior;
- standard utility behavior;
- development tool behavior.

Investigation 049 examines application software as compatibility
evidence.

Investigate:

- application runtime assumptions;
- user-facing software behavior;
- file and device usage;
- direct system access;
- undocumented conventions.

Determine:

- whether applications reveal missing compatibility requirements;
- whether existing compatibility contracts are sufficient;
- whether additional investigations are required.
