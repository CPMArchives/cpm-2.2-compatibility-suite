KEY QUESTIONS


1. USER AREA STATE

Determine how CP/M represents current user area state.

Investigate:

- BDOS user-number functions;
- initial user area after boot;
- state changes;
- persistence across BDOS calls;
- interaction with CCP commands.


Determine:

- where user area state is maintained;
- how applications observe it;
- what state transitions are guaranteed.


2. FILE IDENTITY

Determine whether user area participates in file identity.

Investigate:

- same filename in multiple user areas;
- Open File behavior;
- Make File behavior;
- Delete behavior;
- Rename behavior.


Determine:

- whether files in different user areas are distinct objects;
- how BDOS resolves ambiguous names;
- what applications can assume.


3. DIRECTORY SEARCH VISIBILITY

Determine how user areas affect Search First and Search Next.

Investigate:

- current user area searches;
- wildcard searches;
- multiple matching entries;
- user-area transitions during searches.


Determine:

- which directory entries are visible;
- how user areas are represented;
- whether applications can enumerate other user areas.


4. FCB AND USER AREA INTERACTION

Determine whether FCB operations include user area state.

Investigate:

- Open File;
- Make File;
- Delete File;
- Rename File;
- Sequential operations.


Determine:

- whether FCB contents identify user area;
- whether BDOS implicitly applies current user area;
- whether applications can override user area selection.


5. USER AREA CHANGES

Determine the compatibility behavior of changing user areas.

Investigate:

- BDOS Set User Number behavior;
- USER command interaction;
- file visibility before and after change;
- effect on existing FCBs;
- effect on open searches.


Determine:

- what state changes;
- what state persists;
- what state is application-visible.


6. FILE CREATION AND USER AREAS

Determine how Make File interacts with user areas.

Investigate:

- creation in current user area;
- same filename in different user areas;
- directory representation;
- reopening from different user areas.


Determine:

- whether user area is part of file identity;
- whether applications can create files outside the current user area.

- duplicate filenames;
- wildcard matching.


Determine:

- failure behavior.
