OBJECTIVE

Define the CP/M 2.2 BIOS runtime environment and hardware abstraction
boundary compatibility contract.

Previous investigations established:

- the documented BIOS interface;
- BIOS jump table semantics;
- BDOS interaction;
- device behavior;
- memory layout;
- boot behavior;
- restart behavior.


Investigation 036 determines the broader compatibility boundary created
by the BIOS layer.

The objective is not only to determine what BIOS officially provides,
but to determine what CP/M software historically assumed about BIOS.


Investigate:

- BIOS jump table usage;
- direct BIOS calls;
- BIOS-visible memory structures;
- runtime hardware abstraction;
- vendor BIOS conventions;
- application dependence on BIOS behavior.


Determine:

- which BIOS behaviors are part of the compatibility contract;
- which behaviors are implementation-specific;
- which historical conventions must be preserved for software compatibility.


COMPATIBILITY STANDARD

This investigation must consider:

- documented CP/M 2.2 behavior;
- common CP/M programming practices;
- widespread ecosystem assumptions;
- de facto compatibility requirements.


Do not limit investigation to only documented APIs.
