INVESTIGATION QUESTIONS


1. REQUIREMENT TO TEST MAPPING

- which tests validate each requirement;
- which requirements require manual validation.


2. CONFORMANCE CATEGORIES

- required evidence for each level;
- differences between full and partial compatibility.


3. TEST ORGANIZATION

Determine:

- test categories;
- dependency relationships;
- execution requirements;
- evidence preservation requirements.


4. SOFTWARE CORPUS INTEGRATION

- how software results should be recorded;
- how failures should be classified.


5. PASS/FAIL CRITERIA

- observable success criteria;

- compatibility exceptions.


6. EVIDENCE TRACEABILITY

- how evidence sources are preserved;
- how results can be reproduced.

- compatibility requirement;
- evidence source;

- expected observation;
