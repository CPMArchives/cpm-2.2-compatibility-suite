capture bytes retain prior values and are not evidence.

Decoded results
---------------

SIMPLE: ABC CR -> count 3, data ABC, console ABC CR.
LFTERM: AB LF -> count 2, data AB, console AB CR; LF was not stored/echoed.
EMPTY: CR -> count 0, console CR.
FULL: maximum 3 and ABC -> count 3, data ABC, immediate return with CR output.
BS: AB BS C CR -> count 2, data AC; correction bytes BS SPACE BS.
DEL: AB DEL C CR -> same stored data and correction bytes as BS.
CTRL-E: A ^E B CR -> data AB; ^E emitted CR LF before B.
CTRL-U: AB ^U C CR -> data C; prior line was abandoned after # CR LF.
CTRL-X: AB ^X C CR -> data C; prior characters were erased by backspacing.
CTRL-R: AB ^R C CR -> data ABC; existing line was redisplayed after # CR LF.
CTRL-P: A ^P B CR -> data AB; ^P was excluded and toggled printer echo.
        A preceded the toggle; B and the final CR generated two LIST calls.

The number of BIOS CONIN calls equals the number of scripted input bytes used
in every case. The harness deliberately made CONST report no asynchronously
pending character, avoiding timing-dependent prefetch during echo.

Rejected development run
------------------------

An earlier run allocated and printed records one byte too short, omitting the
final BIOS-CONIN count. Its preceding buffer and output bytes agreed with the
final run, but it is rejected and not used as evidence. The source and binary
preserved here correspond to the complete records above.
