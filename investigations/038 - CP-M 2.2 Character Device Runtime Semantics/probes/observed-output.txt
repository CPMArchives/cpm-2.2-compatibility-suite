  Scripted LISTST: 00 then FF (transport evidence only).

Blocking/readiness
  Empty Function 11, 6/FF, 6/FE: 00 00 00.
  Ready 6/FF first/second: 5A 00.
  Scripted 6/FE twice: 00 00 in this DRI implementation.
  Repeated Function 11: 01 01; subsequent 6/FF: 00; pending Z later reached CCP.
  Function 6 output emitted A, TAB, $, Ctrl-P, B without formatting/toggle action.

Failure boundary
  Reader parity violation C1 passed through BDOS, proving parity normalization is
  a BIOS/device obligation. Punch/list have no standardized BDOS error return in
  Functions 4/5. Optional-device absence, blocking, discard, EOF or host failure
  therefore requires a declared device profile; exact behavior is not universal.
