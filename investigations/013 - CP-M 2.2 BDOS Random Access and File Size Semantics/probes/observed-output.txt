Result-code interpretation
--------------------------

00 success; 01 unwritten data/ordinary missing record; 03 close failure during
seek; 04 unwritten extent on read; 05 new extent cannot be created on write;
06 r2 nonzero/seek beyond physical CP/M 2.2 limit. Code 02 is documented in the
table but not returned by random read; DRI uses 02 for allocation-full writes.
Exact physical BIOS error handling remains separate.
