INVESTIGATION QUESTIONS

1.  TRANSIENT MEMORY BOUNDARY

Determine:

-   what memory range transient programs assume is available;
-   whether programs depend upon specific boundaries;
-   whether boundary behavior is compatibility-visible.

2.  PROGRAM SIZE AND LOADING ASSUMPTIONS

Determine:

-   maximum practical COM program sizes;
-   loader behavior near memory limits;
-   software assumptions about available memory.

3.  STACK AND EXECUTION ASSUMPTIONS

Determine:

-   stack initialization behavior;
-   stack placement assumptions;
-   software dependencies on entry state.

4.  PAGE-ZERO INTERACTION

Determine:

-   which page-zero locations are used by software;
-   which locations are compatibility-visible;
-   whether unusual page-zero usage is historically significant.

5.  MEMORY OVERLAP AND SELF-MODIFYING BEHAVIOR

Determine:

-   whether software relies upon overwriting its own loaded image;
-   whether programs use memory beyond documented boundaries;
-   whether such behavior is common enough to affect compatibility.

6.  SYSTEM MEMORY INTERACTION

Determine:

-   whether applications depend upon CCP, BDOS, BIOS, or system-area
    memory locations;
-   whether such dependencies are direct or indirect.

7.  SOFTWARE ECOSYSTEM USAGE

Investigate software categories:

-   assemblers;
-   compilers;
-   editors;
-   debuggers;
-   games;
-   utilities;
-   applications.

Determine:

-   common memory assumptions;
-   undocumented conventions;
-   de facto compatibility requirements.
