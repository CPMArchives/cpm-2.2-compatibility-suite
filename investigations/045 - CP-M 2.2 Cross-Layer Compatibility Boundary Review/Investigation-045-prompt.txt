INVESTIGATION QUESTIONS

1.  SUBSYSTEM INTERACTION REVIEW

Determine:

-   which behaviors depend on multiple CP/M subsystems;
-   whether existing investigations adequately cover those interactions.

2.  CCP, BDOS, AND BIOS INTERACTION

Determine:

-   whether command execution depends on combined subsystem behavior;
-   whether transient programs observe CCP or BIOS state;
-   whether compatibility requirements cross subsystem boundaries.

3.  STORAGE AND RUNTIME INTERACTION

Determine:

-   whether file behavior depends on runtime state;
-   whether disk behavior interacts with memory, DMA, or execution
    state.

4.  MEMORY AND SYSTEM STATE INTERACTION

Determine:

-   whether memory layout assumptions interact with BDOS, BIOS, or CCP
    behavior;
-   whether software depends upon combined system state.

5.  ERROR AND RECOVERY INTERACTION

Determine:

-   whether failures crossing subsystem boundaries create compatibility
    requirements;
-   whether recovery behavior depends on multiple components.

6.  SOFTWARE ECOSYSTEM REVIEW

Determine:

-   whether historical software exposes additional cross-layer
    assumptions;
-   whether representative software reveals missing compatibility
    boundaries.
